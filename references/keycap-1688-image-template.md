# 键帽类 1688 图片模板

用于键帽现货、来图定制、客户案例、工艺、规格、报价与工厂交付页面。先完成事实拆分，再选择页面；不要把示例字段当成默认事实。

## 1. 先拆分商品路径

分别记录以下字段，不要混写：

| 路径 | 必填字段 |
| --- | --- |
| 现货 | 商品名称、键数/配列、材质、工艺、适配、价格阶梯、发货时间、商品范围 |
| 定制 | 定制对象、MOQ、报价阶梯、来稿格式、打样时间、出货时间、产能口径、服务边界、质检流程 |
| 客户案例 | 案例名称、是否仅作效果参考、键盘是否仅作装机展示、是否允许公开 |

硬规则：

- 现货键数、配列和套装规格不得自动套用到定制路径。
- “套”“个”“颗”必须按原始口径使用。产能按单键帽颗数统计时，要单独说明其只是产能计量，不代表单颗定制商品路径。
- 用户从其他商品复制的规格必须逐条核对；删除不属于当前商品的高度、长度、配列和 MOQ。
- 键帽商品出现装机键盘时，标明“本页商品为键帽，键盘仅作安装展示”或等义说明。

## 2. 买家可读术语

- 对外使用“键位图”“完整键位图”，不使用买家不易理解的 `Kitting`。
- 主题名称严格使用用户确认词，例如“漫画”不得擅自改成“涂鸦”。
- 工艺名称使用已确认的单一口径，例如“热升华工艺”；不要同时堆叠近义工艺名称。
- 把绝对表述改成可验证表述；能由真实微距直接支撑时，可写“高精度印刷”“实拍细节清晰可见”，不要虚构精度数值。

## 3. 主图模板（2560×2560）

### M01 商品与采购入口

- 用真实装机或桌搭图作为主视觉。
- 标题回答“是什么”；副标题回答“现货规格/是否支持定制”；小标签只放一个关键采购门槛。
- 阶梯价信息过多时不塞入主图，转移到 D01。

### M02 现货键位图

- 采用“上方短文案、下方完整键位图”的清晰结构。
- 标题、副标题和红蓝横线保持紧凑节奏；文字行数少，避免把横向键位素材压缩得过小。
- 键帽数量、字符、颜色、图案和相对位置必须保持原样。

### M03 材质与工艺

- 使用真实整机实拍展示总体效果，再使用真实微距突出材质与印刷细节。
- 放大窗必须取自真实局部，不得生成或重绘纹理。
- 文案不得覆盖关键键帽；优先放在图片底部安全区。

### M04 客户定制案例

- 使用两套案例时，优先上下纵向排列并让案例尽量铺满画布；每套产品完整优先于严格等大。
- 为每套案例匹配不同但统一色系的沉浸式桌搭；标明“客户案例仅作效果参考”。
- 定制页不写现货专属键数、配列或套装规格。
- 案例产品不得与手办、绿植或其他道具穿插。移动产品或道具，确保前后关系、接触面和遮挡合理。

### M05 白底商品图

- 使用完整键位图或真实产品抠图；纯白背景，保留极轻自然阴影。
- 原则上不加大段文字；优先让采购方核对数量、颜色与字符。

## 4. 详情页模板（宽 1600，可按内容加长）

### D01 阶梯报价

- 顶部用真实商品场景，底部使用开放式横向价格表。
- 现货与定制分行展示，用细分隔线和窄色带区分；不要使用圆角价格卡片堆叠。
- 每档同时显示数量区间、单位和单价；明确各自 MOQ 与发货条件。

### D02 材质与工艺

- 顶部整宽真实微距；中部用三项开放式卖点；底部可用真实局部细节图。
- 避免重复出现完整键位图。
- 文案不遮挡 Enter 等核心细节；页尾只保留必要的商品范围说明。

### D03 规格与适配

- 使用完整键位图承担整套展示。
- 使用开放式规格栏与适配说明；写“约”“大部分”等边界词。
- 下单前提示核对轴心结构、键位布局与大键规格。

### D04 定制、生产与质检

- 信息较多时保持宽度 1600，并将高度扩展到 3200–3600；不要压缩成拥挤的 2400 高页面。
- 两套客户案例上下纵排；其后依次展示生产/质检证据、交付参数、来稿准入、服务边界和流程。
- 生产与质检照片若来自工厂其他键帽场景，明确标注“仅用于说明通用生产与质检能力”，不得暗示为当前商品同批生产。
- 默认五步流程：图稿文件确认 → 安排打样 → 样品确认 → 安排大货 → 质检发货；只有已确认时才写“全量人工质检”。

## 5. 开放式版式锁

- 让真实素材尽量横向铺满画布。
- 文字直接落在开放背景或适配后的图片安全区；使用整宽色带、细分隔线、短竖线和编号建立层级。
- 不使用大面积圆角矩形卡片、粗卡片边框或多层卡片堆叠。
- 主图保持“字在上、图在下”或“文字浮于图片安全区”的清晰节奏；横向素材不要拆成过多短行。
- 使用暖米白、石墨灰和少量红蓝强调色时，保持跨页面色彩、字体、线条与光线一致。

## 6. 物理一致性验收

逐项检查：

- 产品是否完整，是否超出画布边界。
- 产品字符、图案、纹理、材质、颜色、数量、比例和结构是否未变。
- 产品与桌面是否有自然接触阴影。
- 手办、绿植、电脑和文具是否有合理支撑，并且没有与产品穿插。
- 新背景与产品的主光方向、强度、色温、透视和投影是否一致。
- 微距和放大窗是否来自真实产品局部。
- 中文、价格、MOQ、单位、交期、产能和流程是否由确定性排版完成。
- 200 px 缩略图下，商品、标题和关键采购信息是否仍可识别。

出现穿插、悬浮、错光或阴影不一致时，优先移动/缩小道具、调整真实产品位置或改用干净背景；不要用生成式重绘修补产品。
