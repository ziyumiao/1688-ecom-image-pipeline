# 1688 B2B 工厂店图片包模板

适用于有现货、定制、客户案例、生产或质检证据的工厂店商品。它是一份页面策划与验收模板，不是产品参数表；所有 `{占位字段}` 必须用用户已确认事实替换，缺失时标记“待确认”。

## 1. 先建立事实边界

把事实按采购路径拆开，禁止互相套用：

| 路径 | 只记录该路径已经确认的信息 |
| --- | --- |
| 现货 | 商品名称、SKU/规格、材质、工艺、价格阶梯、起订量、发货条件、商品范围 |
| 定制 | 可定制内容、MOQ、报价口径、来稿格式、打样与大货条件、服务边界 |
| 客户案例 | 案例名称、适用范围、是否仅作效果参考、是否允许公开 |
| 工厂证据 | 生产/质检/包装素材来源、能证明什么、是否属于当前商品批次 |

硬规则：

- 现货 SKU、规格、价格、交期不得自动写到定制路径；反之亦然。
- 价格、MOQ、单位、产能、交期、认证和质检结论必须保持原始口径；不能从其他商品复制。
- 使用其他商品或其他批次的工厂照片时，明确其仅说明通用能力，不能暗示当前商品同批生产。
- 商品以外的主体、配件、安装载体或场景道具，必须在需要时明确“仅作展示”。

## 2. 买家可读文案原则

- 使用买家能理解的商品名称与工艺名称；不使用内部缩写、文件名或生产黑话。
- 标题回答“是什么”，副标题回答“规格/采购条件/适用范围”；一张图只保留一个主要采购动作。
- 把“最好、第一、绝对、永久”等无证据表述改为事实、实拍可见细节或带边界的表述。
- 中文标题、价格、MOQ、单位、交期、认证、流程、Logo 和尺寸标注必须后期确定性排版；不要直接采用生图模型产生的文字。

## 3. 通用主图结构（M01–M05）

| 页面 | 默认职责 | 合适素材 | 采购信息边界 |
| --- | --- | --- |
| M01 | 商品与核心采购入口 | 真实产品主视觉、桌搭或使用场景 | 标题 + 一个核心规格/采购钩子；复杂价格转入 D01 |
| M02 | SKU、规格或完整套装展示 | 完整产品、配件排布、规格图 | 只展示该现货/SKU 已确认配置 |
| M03 | 材质、工艺或真实细节 | 微距、局部实拍、整体实拍 | 放大内容必须来自真实局部；不生成产品纹理 |
| M04 | 客户案例或定制效果 | 可公开案例、真实应用场景 | 明确“案例仅作效果参考”；不套用现货规格 |
| M05 | 白底产品、包装或交付证据 | 白底图、包装、完整产品 | 优先核对产品完整性；避免堆叠大段文案 |

项目 brief 可以重新定义某一页职责；以当前用户确认的页面规划为准。

## 4. 通用详情页结构（D01–D07）

| 页面 | 默认职责 | 仅在事实已确认时写入 |
| --- | --- | --- |
| D01 | 采购入口与分档报价 | 现货/定制分行价格、数量区间、单位、MOQ、发货条件 |
| D02 | 材质、工艺与细节 | 真实可见卖点、微距证据、必要商品范围说明 |
| D03 | 规格与适配 | 尺寸、接口/结构、SKU、适配边界、下单前核对项 |
| D04 | 定制准入、案例与打样 | 来稿要求、服务边界、案例、打样/大货流程 |
| D05 | 生产、质检与交付 | 已确认的生产步骤、质检方式、包装和交付证据 |
| D06 | 工厂与证据 | 可验证的工厂、设备、质检或包装素材及其适用范围 |
| D07 | FAQ 与询盘引导 | 已确认的 MOQ、交期、适配、来稿和售后边界 |

不要为了凑齐页数虚构证据。信息过多时保持画布宽度、增加页面高度，而不是压缩文字和素材。

## 5. 开放式版式与 Campaign Style Lock

- 先锁定 2–3 个主色和 1 个强调色、背景系统、主光方向、阴影强度、字体、线条与图标风格。
- 真实素材尽量横向铺满画布；文字落在开放背景或图片安全区，用细分隔线、短竖线、窄色带和编号建立层级。
- 避免大面积圆角矩形卡片、粗边框和多层卡片堆叠，除非品牌规范明确要求。
- 主图优先“字在上、图在下”或“文字浮于安全区”；横向素材不拆成过多短行。
- 详情页信息多时可纵向加长，但 200 px 缩略图下仍应能辨认商品和关键采购信息。

## 6. 真实产品与物理一致性验收

逐项检查：

- 产品是否完整且未超出画布边界；产品图案、文字、颜色、纹理、材质、数量、比例、形状和结构是否未变。
- 产品是否存在自然接触阴影；新背景与原图的主光方向、强度、色温、透视和投影是否一致。
- 新增道具是否有合理物理支撑，是否与产品发生穿插、悬浮或错误遮挡。
- 放大窗、引线和局部细节是否准确来自真实产品；信息图叠层不必模拟实体阴影。
- 价格、MOQ、单位、交期、产能、流程与质检结论是否均来自确认事实并确定性排版。
- 200 px 缩略图下，商品、标题与关键采购信息是否仍清晰可读。

出现穿插、悬浮、错光、阴影不一致或产品细节失真时，优先重排版、移动/缩小道具、调整真实产品位置或改用干净背景；不要用生成式重绘修补产品。
